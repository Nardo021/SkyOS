# SkyOS Roadmap

## Phase 1 — Desktop Preview ✅

- Tauri v2 + React + Three.js
- Mock + Airplanes.live
- Sky Dome + Ceiling views
- WebSocket stream
- Location / radius / Live toggle
- Fullscreen

## Phase 2 — Real sky mode ✅

- Enhanced N/E/S/W, zenith, horizon styling
- Aircraft trails, distance-based size, altitude colors
- Speed / heading labels
- OpenSky fallback chain (after Airplanes.live)
- Debug map (MapLibre)
- Renderer settings page

## Phase 3 — Projection

- Ceiling output mode, keystone, corner calibration
- Dedicated fullscreen output window

## Phase 4 — Space

- Stars, constellations, moon
- ISS / Starlink via sgp4-rs + CelesTrak TLE
